# Üçüncü taraf bağımlılıklar

## Microsoft Sysinternals PsExec

Paket çalıştırma yolları Microsoft Sysinternals PsExec kullanır. `PsExec.exe` bu repoda veya bu reponun kaynak arşivinde dağıtılmaz.

Resmî indirme ve kullanım bilgisi: https://learn.microsoft.com/en-us/sysinternals/downloads/psexec

İndirdiğiniz `PsExec.exe` dosyasını repo köküne koyun veya PATH üzerinden erişilebilir yapın. PsExec kendi üreticisinin lisans koşullarına tabidir; bu repo PsExec için herhangi bir lisans vermez.

## Windows bileşenleri

Çalışma zamanı Windows PowerShell 5.1, .NET/WPF ve Windows yönetim API'lerine dayanır. Bu Windows bileşenleri repoyla dağıtılmaz.
